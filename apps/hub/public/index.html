TestLens Hub ● running on port {{PORT}}

Receives evidence from API-testing tools and turns it into reviewed bug reports. Nothing is created in your tracker from here: open the TestLens side panel in Chrome/Edge → Incidents → Sync from Hub to review and create.

Postman — paste once into your collection

  1. In Postman, open the collection → Scripts → Post-response (older versions: Tests).
  2. Paste the snippet below. It sends a request to this Hub only when the response is 4xx/5xx, a request error occurred, or a pm.test in the same script failed.
  3. To force a report for a specific request, set pm.variables.set("TL_REPORT", "reason") before the snippet runs.
  4. Run requests as usual. Failures appear in the TestLens side panel after Sync from Hub.
{{SNIPPET}}

Newman (CLI / CI)

Install the reporter from this repo (integrations/postman/newman-reporter-testlens) and run:

newman run collection.json -e env.json -r cli,testlens --reporter-testlens-hub http://localhost:{{PORT}}

Or export a run as JSON (-r json --reporter-json-export run.json) and import the file in the side panel or with the command below.

Import a file (HAR, Newman run JSON, Postman payload)

curl -X POST http://localhost:{{PORT}}/import -H "Content-Type: application/json" -H "X-TestLens-Filename: run.json" --data-binary @run.json

HAR files from DevTools, Charles, Fiddler, Proxyman or Insomnia work too. The TestLens side panel can also import these files directly without the Hub.
